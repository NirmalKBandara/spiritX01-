# SecureConnect

**SecureConnect** is a web-based platform designed with a focus on clean user interfaces and secure authentication flows. It features a modern, responsive frontend built with PHP, HTML5, CSS3, and JavaScript, incorporating high-quality UI components and a polished aesthetic.

## Features

* **Responsive Signup Page**: A dedicated signup interface (`index.php`) featuring a background image and a stylized form container.
* **Secure Authentication Flow**: Integrated login and signup forms with frontend validation to ensure password matching and required field completion.
* **Modern UI Components**:
* **Custom Typography**: Uses 'Poppins' and 'Quicksand' fonts for a professional and friendly feel.
* **Animated Elements**: Includes CSS-based hover effects, gradients, and animated input borders for an interactive user experience.
* **Styled Form Elements**: Custom-designed buttons and input fields with transparency and blur effects.


* **PHP Integration**: The main landing page is built with PHP, allowing for easy backend integration.

## Technical Stack

* **Frontend**: HTML5, CSS3 (Flexbox, Gradients, Animations), JavaScript (ES6+)
* **Backend**: PHP
* **Design**: Google Fonts (Poppins, Quicksand)

## Setup and Usage

1. **Clone the repository**:
```bash
git clone https://github.com/NirmalKBandara/spiritx01-.git
cd spiritx01-

```


2. **Hosting**:
Since the project uses PHP, it needs to be served via a local server like **XAMPP**, **WAMP**, or a built-in PHP server:
```bash
php -S localhost:8000

```


3. **Access the App**:
Open your browser and navigate to `http://localhost:8000/index.php`.
